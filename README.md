## Bookmark Manager

Менеджер закладок, разработанный на **React + TypeScript**.
Приложение позволяет управлять закладками: добавлять, редактировать и удалять. Реализован поиск по названию закладки и смена темы. Данные сохраняются в браузере с помощью `localStorage`, поэтому остаются доступными после перезагрузки страницы.

## Стек

* React
* TypeScript
* Context API
* Custom Hooks
* Local Storage
* Feature-Sliced Design (FSD)
* Сборка: Vite.

## Архитектура

Проект построен с использованием архитектуры **Feature-Sliced Design**, что позволяет разделить приложение на независимые слои и логические модули.
Для управления состоянием используется **Context API**, а переиспользуемая логика вынесена в **кастомные хуки**.

Разработан универсальный хук для управления `local storage` с использованием **generics**.

Цель проекта:
Проект был создан для личного пользования, чтобы не терять важные ссылки, ведущие на лекции/семинары/лабораторные, а также важную информацию к которой хочется вернуться или повторить.

Возможные улучшения:
* Добавить синхронизацию закладок с backend и облачное хранение данных
* Добавить авторизацию пользователей
* Реализовать импорт и экспорт закладок
* Добавить drag & drop для управления порядком закладок
